02 — What you already know

A neural network takes numbers in, learns from them.

You feed it inputs → it passes them through layers of neurons → it produces an output. Each neuron: multiply inputs by weights, sum, activate. Train with backprop. You know this.

🔢

Input layer

One neuron per feature. For our digit: 784 neurons, one per pixel.

🔗

Hidden layers

Fully connected — every neuron talks to every other. This is where patterns are learned.

🏷️

Output layer

One neuron per class. Softmax turns activations into probabilities.

03 — The problem

ANNs on images: two fundamental issues.

Problem 1

Way too many parameters

Take a 256×256 colour photo. Flatten it: 196,608 inputs. One hidden layer of 512 neurons needs:

196,608 × 512 ≈ 100M weights

Just for one layer. This explodes memory & compute — and we haven't even got to the output yet.

Problem 2

Spatial structure is thrown away

When we flatten an image to a list, we lose the fact that neighbouring pixels are related. A cat's eye at position (10,10) is completely disconnected from the pixel next to it at (10,11).

The network must re-learn spatial patterns from scratch — inefficient, and brittle.

Translation problem

A plain ANN trained on a "cat top-left" photo has no idea the same cat appears bottom-right. It treats them as completely different inputs.

05 — The core operation

Convolution: the sliding filter.

A kernel is a tiny grid of learned weights — like a stamp. We slide it over the image, compute a dot-product at each position, and write the result to a new grid called a feature map.

Click "Step through" to animate.

Key insight: the network learns dozens of filters automatically — one for edges, one for curves, one for blobs. Each produces its own feature map.

06 — Controlling size

Stride, Padding & Pooling.

Stride

How many pixels the filter skips each step. Stride 1 = every pixel. Stride 2 = every other — giving a smaller output.

Stride: Output: 5×5
7×7 input · 3×3 filter stepping at chosen stride

Padding

Without padding, output shrinks every layer. Add a border of zeros to keep the same size.

No padding → output shrinks
Max Pooling

Keep the strongest signal

Take each 2×2 region, keep only the max. Halves both dimensions — reducing compute — while keeping the most important activations. Adds position tolerance too.

2×2 max pool → half the size

09 — Extending to colour

Colour images: RGB — three grids stacked.

Everything we just built works the same — we just have depth 3 instead of 1. Each filter now has shape 3×3×3 (27 values) and slides through all three channels simultaneously.

256 × 256 × 3 = 196,608

values going in — but our 3×3×3 filter still only has 27 shared weights.

After layer 1, feature maps may have 32, 64, or 512 channels — each one a learned "concept detector." By layer 4, neurons respond to eyes, ears, wheels, text.

10 — The journey

From ANN to CNN — four steps.

1

Images are grids of numbers

Every pixel = one value. A 28×28 image = 784 numbers. Colour = three of these stacked.

2

ANNs struggle with images

Too many parameters. No spatial awareness. Translation blindness. We needed something better.

3

Convolution = local + shared

A tiny filter slides everywhere. 9 weights, reused across the whole image. Learns patterns in their spatial context.

4

CNN = Conv + Pool + FC

Convolutional layers extract features. Pooling shrinks. Fully-connected layers (your ANN!) make the final decision.
